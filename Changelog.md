## [v3.0.0] UNRELEASED WORKSHOP VERSION (PROJECT UNDER DEVELOPMENT)

### 🌌 Cosmic Vault Synergy (Cross-Mod Engine)
- **Deep Economy Warfare:** `CosmicVaultEconomy` can natively trigger `CosmicWarBridge.forceDeclareWar()` when a faction's famine score exceeds 100, forcing starvation-driven invasions.
- **Faction Trait Scaling Integration:** `CosmicVaultScaling` dynamically reads `Cosmic War` diplomatic traits. If an entrenched (Fortified) faction is invaded, their calculated defensive volume and firepower are globally multiplied by `1.3x`.
- **Unified News API Framework:** Centralized and fortified `CosmicVaultNews` to securely capture and validate news broadcasts from `Cosmic Chronicles`, `Cosmic War`, and `Cosmic Overhaul`.

### 🚀 Added
- **Custom Faction Traits API**: Added `cosmicvaultfaction.lua` exposing `registerCustomTrait`, `getTrait`, and `setTrait`. This allows modders to easily inject custom faction traits that render beautifully in the native Avorion diplomacy UI!
- **Subspace Weather API**: A universal, globally persistent API (`cosmicvaultweather.lua`) allowing any mod to seamlessly generate and clear localized weather hazards.
- **Weather UI Integration**: Native HUD indicators (`cv_weather_ui.lua`) that dynamically render active debuff icons and severe weather warnings for players inside hazard zones.
- `CosmicVaultEconomy` API to track faction resource starvation.
- `CosmicVaultAnomalies` API to spawn persistent interactive POIs.
- **News Broadcaster Interval**: Injected `getUpdateInterval()` into `cosmicvaultnews_server.lua` to ensure the server updates the news queue reliably every second without lagging.
- **CCM Keybind API:** Integrated complete hotkey capture suite (`ccm_keycodes.lua`) with modifier (Ctrl/Alt/Shift) support directly into the config framework.
- **3-Column HUD Layout:** Revamped Cosmic Config Menu with a cleaner Label | Control | Reset UI ratio.
- **Config Reset Buttons:** Added dedicated `anticlockwise-rotation` reset buttons with tooltips to immediately revert settings to defaults.
- **Global Hotkeys:** Added `hotkeyCodex` (ALT+P) and `hotkeyConfigMenu` (ALT+O) to quickly jump into specific UI panels.
- **Custom Economy Engine:** Completely refactored `cosmicvaultgoods.lua` to safely inject custom trade goods into the 5 global vanilla economy arrays dynamically. Added Highlander Shim to `economyupdater.lua` allowing mods to hook dynamic price fluctuations via string callbacks (`CosmicVaultEconomy.registerPriceHook`).
- **Dynamic Combat Scaling API:** Added `cosmicvaultscaling.lua` to calculate defensive OM/Volume arrays natively, allowing logic to spawn mathematically balanced or overwhelming invasion fleets.
- **Codex 3-Level Hierarchy:** Updated the Cosmic Codex UI to support a dynamic 3-level depth (`Category -> Chapter -> Article`) for superior data organization.
- **Territory Expansion API:** Added `cosmicvaultterritory.lua` to allow background mathematical border shifting and station captures without overloading the server.
- **Dynamic Faction Generation API:** Added `expandToSector` to `cosmicvaultterritory.lua` allowing mods to natively spawn and instantiate civilized and pirate outposts into uncharted sectors.
- **Floating Combat Text & DoTs API:** Added `cosmicvaultcombat.lua` exposing `applyDoT` and native logic to render floating combat text for DOTs dynamically.
- **Permanent Buffs API:** Added `applyPermanentFactor` to `cosmicvaultbuffs.lua` to dynamically scale boss shields/damage directly via script natively.
- **Global Ascendancy Tier API:** Added `getGlobalTier` and `setGlobalTier` to `cosmicvaultbuffs.lua` to allow cross-sector tracking of global faction buffs (used heavily by Cosmic Ascendancy).
- **Scaling Sanity Check:** Added a hard cap to `cosmicvaultscaling.lua` to prevent defensive volume scaling from exceeding 500 million (which mathematically crashed Avorion's shipyard generation).
- **Salvage Buff Mapping:** Injected native support for `HiddenSectorSalvageYield` into `cosmicbuff.lua`.

### 🐛 Bug Fixes & Optimization

- **Fixed**: Fixed multiple Avorion API Indexes across various scripts that could cause C++ attempt to index or attempt to call engine crashes.
  - Corrected stat modifier functions (e.g. modifyBaseMultiplier -> addBaseMultiplier).
  - Corrected entity bias functions (e.g. addMultiplyableFactor -> addMultiplyableBias).
  - Replaced invalid faction relation setters with the correct global Galaxy() alternatives.
  - Removed native calls to non-existent functions (e.g. updateStaticAttributes, tryUnloadSector).
  - Corrected distance checks and serialization methods to match vanilla C++ bindings.
- **Fixed**: Added systematic strict validation checks (`if not arg then return end`) across 13 core Vault APIs for maximum stability.
- **Fixed:** `riftmissionutility.lua` unhandled payload arithmetic crash and table compilation failure. The mission completion UI logic assumed `Sector():getValue("rift_depth")` and `server:getValue("cv_rift_extractions")` natively returned numbers and immediately executed arithmetic comparisons (`>= 50`) and additions (`count + 1`) on them. If a database corruption pushed a string into these slots, the logic instantly crashed (`attempt to compare string with number`). Furthermore, the logic blindly pushed `arguments` into an `unpack()` function. If the server supplied a primitive string instead of an array table, the Lua unpacker fatally crashed (`bad argument #1 to 'unpack' (table expected, got string)`). Fixed all vulnerabilities by wrapping the payloads in rigid mathematical type-checks.
- **Fixed:** `init.lua` and `server.lua` fatal initialization blockages. The core galaxy logic natively attempted to attach 4 massive background processing loops (`cosmicvaultnews_server.lua`, `cosmicvaultterritory_server.lua`, `cosmicvaultweather_server.lua`, `cosmicvaultriftescalation_server.lua`) using relative file strings. Because Avorion strict-matches C++ script binding lookups, the engine completely failed to load any of them on sector startup! Replaced all bindings with absolute paths (`"data/scripts/server/..."`). Also attached `cosmicvaultcinematic.lua` directly to the player `init.lua` to guarantee it runs correctly on the client.
- **Fixed:** `infoCv.lua` silent injection failure. The codex info builder attempted to populate the UI by calling `invokeFunction('ui/cosmiccodex', ...)`. Because Avorion uses absolute path string hashing, this relative string call failed natively on the C++ backend, leaving the Cosmic Vault codex completely empty! Hardened the invocations to strictly map to `"data/scripts/player/ui/cosmiccodex.lua"`.
- **Fixed:** `cosmiccodex.lua` fatal Lua pattern injection vulnerability. When players searched the codex library using the UI search bar, the engine blindly passed the input text directly into `string.match`. Because Lua pattern matching executes special characters (`[`, `%`, `?`, `*`), a user typing a simple search query like `[Error]` or `What?` would trigger a fatal pattern exception and instantly crash the entire client UI thread! Replaced the endpoint with `string.find(..., 1, true)`, strictly disabling pattern evaluations and enforcing mathematically safe plain-text searching.
- **Fixed:** `cosmiccodex.lua` unhandled cross-mod payload exceptions. The script blindly pushed `title` and `text` arguments from external mod APIs directly into the UI tree compiler without verifying their structural integrity. If a third-party mod hooked into the Codex and accidentally passed `nil` or a raw primitive, the tree builder would instantly crash. Hardened the endpoints with rigid mathematical type-enforcements (`if type(title) ~= "string" then title = tostring(title) or "" end`).
- **Fixed:** `cosmicconfigmenu.lua` fatal unhandled network payload structural injections. The global configuration synchronization APIs (`syncCCMSettings` and `requestCCMSync`) blindly parsed keys from client-injected payload structs and immediately threw them into string concatenations (`"ccm_" .. k` and `"ccm_" .. item.namespace`). If a corrupted packet, malicious client injection, or malformed database struct passed a non-string index (like a primitive number or a Lua table address), this concatenation would instantly throw an `attempt to concatenate a table value` arithmetic exception and irreversibly crash the server threading engine! Wrapped all key parsers in rigid mathematical type guards (`type(k) == "string"`).
- **Fixed:** `cv_rift_escalation_tracker.lua` fatal entity death blockage. The tracker assumed `Server():getValue("cv_rift_guardian_kills")` would natively return a number and immediately executed an arithmetic addition on it (`count + 1`). If a database corruption or external mod pushed a string into this slot, the tracker instantly crashed, blocking the rest of the entity's `onDestroyed` routine! Wrapped the payload extraction in a strict mathematical type-check (`type(count) == "number"`).
- **Fixed:** `cv_weather_debuff.lua` catastrophic premature termination bug causing permanent loss of weather penalties. Upon server restart or sector RAM load, the script executed an engine capability check (`Sector():hasScript("sector/cv_weather_controller.lua")`) to ensure a storm was active before applying penalties. However, because Avorion strictly parses absolute file paths on `hasScript()` bindings, this relative string match systematically failed. The engine assumed the storm was gone, immediately called `terminate()`, and permanently wiped out all weather penalties on every ship in the sector upon server restart! Standardized the script existence check to the absolute engine path (`"data/scripts/sector/cv_weather_controller.lua"`).
- **Fixed:** `cv_weather_debuff.lua` player faction immunity bypass. The script previously applied Dark Matter Fog immunities natively by scanning if a ship belonged to a faction named "The Eclipse" (`faction.name == "The Eclipse"`). This allowed a player to maliciously rename their alliance or player faction to "The Eclipse" to permanently bypass fog debuffs! Sandboxed the immunity loop behind strict `not faction.isPlayer` and `not faction.isAlliance` enforcements.
- **Fixed:** `cv_weather_debuff.lua` memory corruption vulnerability on SQL sector restore. The API blindly executed `data.type` without verifying the payload structural type. If a corrupted SQL table injected a primitive string or number instead of the table struct, the server thread would immediately crash (`attempt to index local 'data' a nil value`). Locked the endpoint behind strict mathematical type-enforcements.
- **Fixed:** `cosmicvaultweather_server.lua` fatal client synchronization disconnects. Because Avorion natively executes absolute string matches for cross-script evaluations, this relative path call was systematically ignored by the engine, meaning clients were never notified of live storm occurrences! - **Fixed:** `cosmicvaultweather_server.lua` memory corruption vulnerability on server restore and background tracking. The API blindly executed `weather.expiry` and `data.activeWeathers` without verifying their payload types. - **Fixed:** `cosmicvaultterritory_server.lua` unhandled structural exceptions and primitive injections in the global territory flipping engine.
