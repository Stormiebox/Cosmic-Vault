# 🌌 Cosmic Vault

*The foundational API library and core framework for the Cosmic Series.*

## 📖 Overview
Cosmic Vault acts as the central spine for all other Cosmic mods. It provides shared libraries for the Cosmic Codex, unified UI tabs, asynchronous task scheduling, and secure communication layers between the client and dedicated servers.

## ✨ Features
<details>
<summary><b>Click to expand features</b></summary>

- **Cosmic Codex API:** Universal in-game encyclopedia injection framework.
- **Custom Economy Engine:** Natively inject trade goods and dynamic price fluctuations without overriding vanilla background scripts.
- **Async Task Scheduler:** Prevents server hitching by distributing heavy script loads across multiple ticks.
- **Unified UI System:** Hooks into the player's main window seamlessly without conflicting with other mods.
- **Security Layer:** Validates server callbacks to prevent exploitative remote code execution.
</details>

## ⚙️ Requirements
- Avorion v2.0+
- Dependencies: **None**
- This mod is the core foundation for **all** cosmic series mods.

## 🚀 Installation
1. Place the folder in:
   - **Windows:** `%AppData%\Avorion\mods\`
   - **Linux:** `~/.avorion/mods/`
2. Enable **Cosmic Vault** in **Settings -> Mods**.
3. Restart Avorion when prompted.
